## 🌌 Overview

AI Air Canvas is a Python application that uses OpenCV and MediaPipe to track hand movements and turn gestures into a drawing experience. It explores computer vision and natural human-computer interaction.

## ✨ Features

- 🖐️ Real-time hand tracking
- ☝️ Finger-gesture detection
- 🎨 Drawing through hand movement
- ⌨️ Keyboard-based color controls
- 🧹 Clear the canvas
- 💾 Save drawing output

## 🧰 Technology Stack

| Technology | Purpose |
|---|---|
| Python | Application logic |
| OpenCV | Image and video processing |
| MediaPipe | Hand landmark / gesture tracking |
| NumPy | Numerical and array operations |

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mallikarajapure-collab/AI-Air-Canvas.git
cd AI-Air-Canvas
```

### 2. Create and activate a virtual environment

**Windows PowerShell**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Start the application

```powershell
python app.py
```

Allow camera access if prompted. The app uses the camera for hand tracking.
